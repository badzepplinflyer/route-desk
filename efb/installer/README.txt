Route Desk tablet app for Microsoft Flight Simulator 2024
=========================================================

Easy way
  1. Right-click the zip and choose "Extract All...".
  2. Open the extracted folder and double-click "Install Route Desk".
     If Windows shows "Windows protected your PC", click "More info",
     then "Run anyway". The installer only copies the routedesk-efb
     folder into your sim's Community folder.
  3. Start (or restart) the sim, open the cockpit tablet, tap Route Desk.

Manual way
  Copy the "routedesk-efb" folder into your Community folder:
    Microsoft Store / Xbox app / Game Pass:
      %LOCALAPPDATA%\Packages\Microsoft.Limitless_8wekyb3d8bbwe\LocalCache\Packages\Community
    Steam:
      %APPDATA%\Microsoft Flight Simulator 2024\Packages\Community
  (Paste the path into the File Explorer address bar.) If you chose a custom
  location for add-ons when you installed the sim, use that Community folder.

Updating: run the installer again; it replaces the old version.
Removing: delete the routedesk-efb folder from your Community folder.
